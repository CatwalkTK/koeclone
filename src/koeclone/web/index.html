はじめに

あなたの声を、安全に扱うために

koecloneは、本人の声を本人が使うためのローカル音声生成ツールです。音声・文章・生成結果を外部へ送信しません。

✓

本人の声のみ登録可能

あなた自身が話した声で、利用する権利を持つ録音だけを登録してください。

!

禁止用途

なりすまし、詐欺、嫌がらせ、他人を誤認させる用途には使用できません。

声の登録

声のもとを用意する

静かな場所で直接録音するか、本人のWAV / MP3ファイルを選んでください。

登録済みの声

削除すると、参照音声・同意録音・生成した音声とサイドカー・生成履歴がすべて消えます。元に戻せません。
